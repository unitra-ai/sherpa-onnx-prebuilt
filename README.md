# sherpa-onnx prebuilt binaries

Prebuilt shared libraries of [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx)
(Apache-2.0, see `LICENSE`) as consumed by Unitra's build. This repository holds
release archives only; it carries no source.

Each release's archives are verified by the SHA-256 table in the consuming build.
